Fase 1: O Que é Versionamento e Criando o Repositório (30 min)

💡 Conceito: Git vs. GitHub

Git: É o sistema de controle de versão distribuído. Pense nele como uma máquina do tempo local que registra e gerencia as alterações feitas em seus arquivos. Ele roda na sua máquina.
GitHub: É um serviço de hospedagem de repositórios Git baseado na nuvem. Ele serve como o "local central" onde as pessoas podem colaborar, compartilhar código e guardar o projeto de forma segura.
